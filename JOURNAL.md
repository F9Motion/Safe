# September 26: Doing safe
Let's do a speedrun and make a mechanical safe in one day. In Blender, right away we open scene properties and change meters to centimeters, I initially made millimeters out of habit from making a mechanical keyboard. We set Unit scale to 0.01. We did all this so that we could then print on a 3D printer and so that the printer doesn't think it's very large, etc. On the keyboard, press N and now, oh miracle, we see its coordinates, how much it is rotated, and the size in centimeters along all x y z axes. This is necessary so that when making a safe, we don't guess what size is there, but simply see in the right window what size is there. Select the cube and set the proportions to 22 by 28 by 15. I chose this size because it can be printed on a 3D printer the size of A4 paper. We make another cube for it and set the size proportions exactly the same but slightly smaller, but leave one axis long. We need this cube only so that we specify it in the Boolean modifier and cut it out of that 22 by 28 by 15 cube, and we made one axis larger because we need to make a hole for the door. After that, create a new cube and set the size to 2 by 28 by 15. This will be the door for the safe, not thick so as not to take up much space, and thick enough to be solid. If I miss something, forgive me, I am writing this after I made the safe and looking at the video and my memory, explaining why and what I did it for. I will add text, and if anyone didn't know, to write it you need to press Tab. When I first wrote text, after half an hour I realized that you need to press Tab; nowhere is it written that you need to press Tab. I initially thought that you need to select the text from the layer list and then write in the properties. If Hack Club sponsors Blender, please tell them this to save time. So continuing, press Tab, remove the text and write "what's in me?" there, it's not necessary to write exactly this, it's rather just a decoration.
Now we need knobs to enter the code, I made 3 of them. A standard cylinder does not suit us because it is too round, so we create a plane and press Ctrl+1. This made an 8-sided shape out of a square, since this is just a modifier, don't forget to apply it with Ctrl+A. We need an octagon because 4 is too few, 16 is too many, 8 is the golden mean.
At first I wanted to make Minecraft items instead of numbers and letters, but I don't have enough experience to model them, so I changed my mind and wanted to put numbers, but again changed my mind because it's an octagon and there are 10 numbers, so I made letters from A to H. So to write these letters, first you need to make a 3D octagon out of a 2D octagon, for this we go to edit mode, select everything by pressing A and press E to extrude, now we have a 3D octagon. I made its thickness 2 cm so that the letters would fit and so it wouldn't be thick. I got carried away, writing for an hour about what I did for half an hour, next I will make the text general, let's go. The point of the safe is to protect what is inside. My safe works like this: 3 wheels need to be turned so that these letters stand perfectly as in the password, for example agh (any combination)
and exactly in this rotation of each wheel, make holes that match perfectly. So that when you pull the stick when the password is matched, the holes align perfectly and the holes don't interfere when you pull out the stick (you will add the stick later, it will lock the door), and when the password is incorrect, the holes interfere with pulling out the stick and the door wouldn't open. For the stick you can simply take a sphere and set the desired size, and make the holes, just like with the body, using the Boolean modifier. You can make the hole square like I did, just don't forget to cover the mechanism with a cube so that when you put something on top of the safe, that item doesn't touch the mechanism and interfere with it. For originality, I also added the text "safe not for cash, for sneaks" (Of course I later corrected it to snacks, I don't know English well, so I wrote everything in Russian and gave it to AI to translate it all into English as is without changes.) Well, basically that's all, I also added materials and colored some parts.

**Total time spent: 2 hours**
